# 小书童语音对话验证

入口：http://127.0.0.1:5173/game

点击右下角小书童 → 开始语音 → 允许麦克风 → 说一句后停顿约一秒。

文字模型：WorkBuddy 国内代理 `deepseek-v4.1-flash`。识别：本机 CPU 上的 SenseVoiceSmall int8。朗读：Edge 晓晓女声，语速 0.85、音调 -8Hz、音量 -5%。不使用 DeepSeek 官方 Key。

## 已通过

- 后台 17 项测试、前端音频处理 4 项测试。
- 前端生产构建。
- 三段不同中文录音经过后台识别、模型回答和朗读，第二轮记住“小林”的名字。见 `three-turn-verification.json` 和 本机生成的 `answer-1.mp3` 至 `answer-3.mp3`（不随仓库分发）。
- 浏览器用合成中文录音模拟麦克风，完成三轮连续真实模型对话；朗读期间麦克风轨道禁用，回答后恢复聆听。
- 文字输入沿用语音对话上下文。
- 停止回答、结束语音、关闭面板和离开页面。
- 拒绝麦克风权限时给出提示，保留文字入口。
- 朗读失败时保留回答；关闭时取消等待，迟到回答不会播放。
- 390px 手机宽度布局。
- 麦克风授权仍在等待时关闭，返回的录音流会立即释放。
- 页面离开事件清理；取消连续对话后，单轮回答结束自动释放麦克风。

浏览器报告：`browser-verification.json`、`lifecycle-verification.json`。仓库保留截图：`desktop-conversation.png`；其他截图为本机验收产物。

以上自动化浏览器录音测试使用模拟设备，没有使用用户的物理麦克风。用户随后已在实际页面测试，并明确反馈“能听懂，也能正常朗读”，因此真实麦克风识别与女声朗读的基本使用验收通过。这是用户确认的结果，不代表已完成多设备、不同噪声环境或长时间稳定性测试。采用先听后说的半双工模式，朗读期间可点“停止回答”，不支持同时开口打断。

当前页面等待整段音频返回后播放；角色为 SVG 抱书形象和状态动画。完整启动与接口说明：`shici-app-server/GAME-COMPANION.md`。
